==================================================
 前代悠月選手 骨折中リハビリ＆復帰ロードマップ PWA
==================================================

【概要】
前代悠月選手が骨折固定期間中から完全復帰まで、日々の栄養管理・安全な練習管理・週間ロードマップをスマホやパソコンで簡単かつインタラクティブに管理できるProgressive Web App (PWA) です。

【ファイル構成】
- index.html    : PWAアプリ本体 (HTML/CSS/JS)
- manifest.json : PWA設定ファイル (ホーム画面追加・アイコン等)
- sw.js         : Service Worker (オフライン動作＆キャッシュ機能)
- README.txt    : 本説明ファイル

【使い方】
1. このZIPファイルを解凍し、任意のWebサーバーやGitHub Pages、Vercel等にアップロードするか、ローカル環境で index.html を開きます。
2. スマホ（Safari / Chrome）で開いた場合、「ホーム画面に追加」を行うことで完全な単体アプリ（PWA）として起動できるようになります。
3. チェック状態やロードマップの達成率はブラウザの LocalStorage に自動保存されます。
